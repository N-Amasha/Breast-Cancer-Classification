## Feature Scaling

### What is Feature Scaling?

Feature scaling transforms numerical features so that they are represented on a comparable scale.

In this project, **StandardScaler** from Scikit-learn is used.

Standardization transforms a value using:

```text
z = (x - mean) / standard deviation
```

After standardization:

* Mean is approximately **0**
* Standard deviation is approximately **1**

---

## Why StandardScaler Was Used

Although the dataset features generally use the same 1–10 scoring range, scaling is still useful for the machine learning techniques used in this project.

Standardization is particularly important for:

* **Logistic Regression**
* **Support Vector Machine (SVM)**
* **Principal Component Analysis (PCA)**

SVM can be affected by feature scale because it uses distances and margins.

PCA is especially sensitive to feature variance, so standardizing the features helps prevent features with larger variation from dominating the principal components.

---

## Missing Values

The original dataset contains **16 missing values** in the `Bare_Nuclei` feature.

The missing value marker `?` is replaced with `NaN`, and `Bare_Nuclei` is converted to a numeric data type.

StandardScaler cannot independently solve missing values.

Therefore, in the final machine learning pipeline, missing-value imputation is performed before scaling.

The final modelling pipeline uses preprocessing in the correct order:

```text
Missing-value imputation
        ↓
StandardScaler
        ↓
PCA (if used)
        ↓
Machine Learning Model
```

The preprocessing steps are fitted using the training data to help prevent data leakage.
