## 2. Dataset

**Dataset:** Breast Cancer Wisconsin (Original)

The original dataset contains:

* **699 observations**
* **9 predictive features**
* **1 target/class variable**
* **1 sample ID column**
* Feature values generally range from **1 to 10**
* Missing values represented by `?`

The nine predictive features are:

1. Clump Thickness
2. Uniformity of Cell Size
3. Uniformity of Cell Shape
4. Marginal Adhesion
5. Single Epithelial Cell Size
6. Bare Nuclei
7. Bland Chromatin
8. Normal Nucleoli
9. Mitoses

The original target classes are:

* `2` = Benign
* `4` = Malignant

## 4. Outlier Investigation

Potential statistical outliers were investigated using:

* Boxplots
* Interquartile Range (IQR) method

The analysis identified statistical outliers in several features.

However, the values of the predictive features are within the valid scoring range of approximately **1–10**.

Therefore, statistical outliers were **not automatically removed**.

### Reason for retaining outliers

An unusual value does not necessarily mean that the observation is incorrect.

Since this is a medical dataset, unusual measurements may contain useful information about differences between benign and malignant cases.

Therefore, the decision was to:

* Identify potential statistical outliers.
* Check whether values are within the valid feature range.
* Retain valid observations.
* Avoid removing observations only because they are statistical outliers.

---

## 5. Feature Selection

Feature selection was performed using the **ANOVA F-test**.

The ANOVA F-test was used to investigate whether each predictive feature showed a statistically significant difference between the two target classes.

The significance level used was:

`α = 0.05`

A feature was considered statistically significant when:

`p-value < 0.05`

The features were ranked according to their F-scores.

### Result

All nine predictive features produced p-values below `0.05`.

Therefore:

* All **9 features were retained**.
* No feature was removed using the ANOVA significance criterion.
* `Uniformity_Cell_Size` produced the highest F-score.
* `Uniformity_Cell_Shape` and `Bare_Nuclei` also produced very high F-scores.
* `Mitoses` produced the lowest F-score, but it was still statistically significant and was therefore retained.

ANOVA was used for feature selection, while PCA was handled separately as the dimensionality reduction technique in another member's work.

## 10. Key Conclusions

The main conclusions from Member 03's analysis are:

1. The original target labels were successfully encoded from `2/4` to `0/1`.
2. Statistical outliers were identified using boxplots and the IQR method.
3. The identified unusual values were retained because they remain within the valid feature range and may contain meaningful information.
4. ANOVA F-test was used for feature selection.
5. All nine predictive features had statistically significant p-values below `0.05`.
6. Therefore, all nine features were retained.
7. `Mitoses` had the lowest F-score but remained statistically significant.
8. PCA was used separately for dimensionality reduction rather than removing features through ANOVA.
